# Restaurant Backend — Node.js REST API

## Overview
Full-stack backend developed for a local restaurant client
in Ouagadougou, Burkina Faso. Project completed but not 
deployed due to client-side decision.

## Tech Stack
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MySQL
- **Architecture:** REST API

## Features
- Menu management
- Order handling
- Public-facing API endpoints
- Database integration

## Status
✅ Fully functional — pending client deployment
